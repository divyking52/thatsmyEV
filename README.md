# ThatsmyEV

Premium EV research landing experience.

## Standalone (deployed)

Static single-page build lives in [`standalone/`](./standalone/):

- `standalone/index.html` — inline CSS + JS
- Media loaded from Storebox CDN (`media.storebox.ai`)

Open locally:

```bash
npx serve standalone
```
